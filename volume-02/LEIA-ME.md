# Volume 02 — Funções e estruturas de dados

Coloque esta pasta do GitHub no computador como pasta local `formacao-dados-ia/volume-02`.

- `formacao-dados-ia/volume-02/exemplos`: programas completos das seções, para ler e executar.
- `formacao-dados-ia/volume-02/exercicios/atividades.txt`: enunciados, entradas e resultados esperados. Crie seus arquivos de exercício nessa pasta local.
- `formacao-dados-ia/volume-02/projeto/loja_funcoes.py`: começa somente com comentários; escreva sua implementação do projeto da seção 23.
- `formacao-dados-ia/volume-02/solucoes`: respostas completas para consultar depois de tentar. A referência do projeto é `formacao-dados-ia/volume-02/solucoes/loja_funcoes.py`.
- `formacao-dados-ia/volume-02/exercicios/testes-projeto.md`: sequências de entrada para conferir a loja. Não é um arquivo importado pelo programa.

Abra a pasta local `formacao-dados-ia` no VS Code, abra um programa, salve e use Run Python File in Terminal. Para comando, abra o terminal na pasta local que contém o programa e use `py nome_do_arquivo.py`, ou o comando Python validado no seu sistema. As respostas de input são digitadas no terminal.

Somente Python local; sem bibliotecas adicionais ou serviços pagos. Dados não são preservados ao encerrar. Não sobrescreva sua implementação com uma atualização dos materiais.
